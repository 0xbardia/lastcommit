# LastCommit roadmap

## V1 — current

- Contract-backed Proof of Abandonment.
- GenLayer semantic review over registered public evidence.
- Configuration-bound succession eligibility.
- Wallet-signed registration, updates, and reviews.
- Public proof pages with immutable review snapshots and bounded history.

## After submission

- Measure real review latency and Studio rate-limit behavior before changing retry policy.
- Add a supported indexer only when contract-backed pagination no longer gives acceptable explorer performance.
- Replace renderer-level DNS/redirect assumptions only when GenLayer exposes a safe, supported control surface.

V1 intentionally does not include tokens, staking, DAO governance, automatic asset transfer, social scraping, or a second arbitration network.
